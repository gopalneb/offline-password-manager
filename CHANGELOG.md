# Changelog

All notable user-facing changes are documented here.

## 1.4.1 - 2026-08-18

- Fixed username and password copy actions in browser previews that deny the modern Clipboard API.
- Retained native Android sensitive clipboard handling.

## 1.4.0 - 2026-08-18

- Added Android Autofill service registration and Save prompts for compatible login forms.
- Added PIN-gated review before Autofill credentials are encrypted into the vault.
- Added Autofill enable/manage controls.

## 1.3.0 - 2026-08-18

- Added encrypted .pvault export.
- Added clean-install restore with recovery code and a new local PIN.
- Added backup status and migration guidance.

## 1.2.0 - 2026-08-17

- Added unique recovery codes.
- Added local recovery-code text export.
- Added forgotten-PIN recovery without deleting saved entries.

## 1.1.0 - 2026-08-17

- Replaced device authentication with an app-specific six-digit PIN.
- Removed website URL and hint/note fields.
- Improved Samsung and Honor compatibility.
- Fixed password eye-button alignment.

## 1.0.0

- Initial local-only vault, login editor, copy actions, and Android shell.
